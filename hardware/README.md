# Hardware Design

This folder contains the KiCad PCB design files for the Smart Solar Charge Controller for Low-Cost Off-Grid Devices.

## Project Details
- **Project:** Smart Solar Charge Controller
- **Application ID:** VK26-IITH-SE-0098
- **Controller algorithm:** Perturb and Observe (P&O) MPPT
- **Target system:** 12 V off-grid solar applications

## Files
- `mppt_controller.kicad_pcb` — PCB layout
- `mppt_controller.kicad_pro` — KiCad project settings
- `fp-lib-table` — Footprint library configuration
- `MPPT_Custom.pretty/` — Custom component footprints

## Design Status
The PCB design is under development. Final Design Rules Checker verification and component footprint validation must be completed before fabrication.

- KiCad PCB Editor
